# Снять отчёт с гашением (Z-отчёт)

**Операция:** `СнятьОтчетСГашением` · **метод:** `ЗакрытьСмену` · **флаги:** `--no-dry-run --allow-fiscal`

Закрывает смену. Фискальный документ, уходит в ОФД.

## Запрос

```json
{"СнятьОтчетСГашением":{"Пароль":"30"}}
```

| Поле | Тип | Обяз. | Описание |
|---|---|---|---|
| `Пароль` | строка или число | нет | пароль кассира |

## Примечания

* Повторный вызов на закрытой смене даёт ошибку ККТ «Смена закрыта - операция невозможна».
* Для новых чеков смену нужно открыть снова.
