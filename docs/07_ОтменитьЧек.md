# Отменить чек

**Операция:** `ОтменитьЧек` · **метод:** `ЗакрытьСессиюРегистрацииКМ` · **флаги:** `--no-dry-run`

## Запрос

```json
{"ОтменитьЧек":{"Пароль":"30"}}
```

| Поле | Тип | Обяз. | Описание |
|---|---|---|---|
| `Пароль` | строка или число | нет | пароль кассира; метод его не использует |

## Полный дамп (форма вызова)

```
→ {"jsonrpc":"2.0","id":101,"method":"ЗакрытьСессиюРегистрацииКМ","params":[
     {"type":"str","value":"ATOL_KKT_1C_V10_X_ESM#0"}]}

← {"jsonrpc":"2.0","id":101,"result":{"method":"ЗакрытьСессиюРегистрацииКМ","type":"bool","value":true,
     "returned":"VTYPE_BOOL=true","out":[],"outScalars":[],
     "componentData":["ЗакрытьСессиюРегистрацииКМ"]}}
```

## Ответ шлюза

```json
true
```

## Примечания

**Отдельной отмены чека в наборе из 36 методов компоненты НЕТ.** Требования (раздел 3.5)
предписывают при отмене чека вызывать `ЗакрытьСессиюРегистрацииКМ()` — на это и сделано
отображение. Отображение требует подтверждения на реальном сценарии отмены.
