# Возврат

**Операция:** `НапечататьЧек` · `ТипЧека: "Возврат"` · **метод:** `СформироватьЧек` (OperationType = 2)
**Флаги:** `--send файл.json --no-dry-run --allow-fiscal`

## Запрос

Отличается от продажи **ровно одним полем**:

```json
{"НапечататьЧек":{
  "ТипЧека":"Возврат","СНО":1,"Кассир":{"Имя":"Администратор"},
  "Оплата":[1,0,0,0,0,0,0,0,0],
  "Товары":[{"Наименование":"Тестовая позиция","Количество":1,"Цена":1,"Сумма":1,
             "Подразделение":0,"СтавкаНДС":"5","НомерНалога":"5",
             "ПризнакПредметаРасчета":1,"ПризнакСпособаРасчета":4}],
  "СуммаСкидкиНаЧек":0}}
```

Поля — как в `01_Продажа.md`.

## Ответ шлюза

```json
{"НомерЧека":"20","НомерДокумента":"415","ФлагРегистрацииККТ":true,"НомерККТВМагазине":0,
 "ФискальныйПризнак":"2255683210","ОшибкаПечати":false,"НомерУведомленияМТ":null}
```

## Примечания

* Возврат **маркированного** товара требует заново проверить КМ с `ЭтоВозврат: true` — см. `08_ПроверитьКодыМаркировки.md`.
* Возврат расхода — `ТипЧека: "ВозвратРасхода"` (OperationType = 4).
