# Продажа

**Операция:** `НапечататьЧек` · `ТипЧека: "Продажа"` · **метод:** `СформироватьЧек` (OperationType = 1)
**Флаги:** `--send файл.json --no-dry-run --allow-fiscal`

## Запрос

```json
{"НапечататьЧек":{
  "ТипЧека":"Продажа","СНО":1,"Кассир":{"Имя":"Администратор"},
  "Оплата":[1,0,0,0,0,0,0,0,0],
  "Товары":[{"Наименование":"Тестовая позиция","Количество":1,"Цена":1,"Сумма":1,
             "Скидка":0,"Подразделение":0,"СтавкаНДС":"5","НомерНалога":"5",
             "ПризнакПредметаРасчета":1,"ПризнакСпособаРасчета":4}],
  "СуммаСкидкиНаЧек":0}}
```

## Поля запроса

| Поле | Тип | Обяз. | Описание |
|---|---|---|---|
| `ТипЧека` | строка | да | `Продажа` / `Возврат` / `Расход` / `ВозвратРасхода` → OperationType 1/2/3/4 |
| `СНО` | число | нет | 1-Общая, 2-УСН Доход, 4-УСН Д-Р, 8-ЕНВД, 16-ЕСХН, 32-Патент. Пусто — из `config.json` |
| `Кассир.Имя` | строка | нет | `CashierName`; пусто — `cashier_name` из `config.json` |
| `Оплата` | 9 чисел | да | [0] нал, [1] безнал, [2] предоплата, [3] постоплата, [4] встречное, [5..8] резерв |
| `Наименование` | строка | да | тег 1030 |
| `Количество` | число | да | количество |
| `Цена` | число | да | цена за единицу |
| `Сумма` | число | да | итог по позиции; проверяется `Количество × Цена − Скидка` |
| `Скидка` | число | нет | скидка по позиции |
| `Подразделение` | число | нет | тег 1198 |
| `СтавкаНДС` | строка | да | `none`, `0`, `5`, `7`, `10`, `20`, `22`; НДС считается как `Сумма × ставка/(100+ставка)` |
| `НомерНалога` | строка | нет | альтернатива `СтавкеНДС` |
| `ПризнакПредметаРасчета` | число | нет | тег 1212, по умолчанию 33 |
| `ПризнакСпособаРасчета` | число | нет | тег 1214, по умолчанию 4 |
| `СуммаСкидкиНаЧек` | число | нет | скидка на чек |
| `ЭлПочтаТелефон` | строка | нет | тег 1008 |

## Ответ шлюза

```json
{"НомерЧека":"19","НомерДокумента":"414","ФлагРегистрацииККТ":true,"НомерККТВМагазине":0,
 "ФискальныйПризнак":"1040188424","ОшибкаПечати":false,"НомерУведомленияМТ":null}
```

| Поле | Описание |
|---|---|
| `НомерЧека` | номер чека в смене (`ShiftClosingCheckNumber`) |
| `НомерДокумента` | номер фискального документа (`CheckNumber`) |
| `ФлагРегистрацииККТ` | `true` — чек фискализирован |
| `ФискальныйПризнак` | ФПД (`FiscalSign`) |
| `ОшибкаПечати` | `true` — фискализирован, но бумага не напечатана; повторять чек нельзя |
| `НомерУведомленияМТ` | номер уведомления о реализации МТ (`MTNumber`) |

## Примечания

* Сумма позиций обязана совпадать с суммой оплат — шлюз проверяет это до отправки.
* `Электронно` всегда передаётся логическим (`{"type":"bool"}`); строка даёт ошибку типа 999.
* При `ОшибкаПечати = true` повторный вызов создаст **второй** фискальный документ.
