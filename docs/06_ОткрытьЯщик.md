# Открыть денежный ящик

**Операция:** `ОткрытьЯщик` · **метод:** `ОткрытьДенежныйЯщик` · **флаги:** `--no-dry-run`

## Запрос

```json
{"ОткрытьЯщик":{"Пароль":"30"}}
```

| Поле | Тип | Обяз. | Описание |
|---|---|---|---|
| `Пароль` | строка или число | нет | пароль кассира; метод компоненты его не использует |

## Полный дамп (форма вызова)

```
→ {"jsonrpc":"2.0","id":101,"method":"ОткрытьДенежныйЯщик","params":[
     {"type":"str","value":"ATOL_KKT_1C_V10_X_ESM#0"}]}

← {"jsonrpc":"2.0","id":101,"result":{"method":"ОткрытьДенежныйЯщик","type":"bool","value":true,
     "returned":"VTYPE_BOOL=true","out":[],"outScalars":[],"componentData":["ОткрытьДенежныйЯщик"]}}
```

## Ответ шлюза

```json
true
```
