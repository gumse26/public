# Внешний протокол шлюза gate.atol.piot

Шлюз принимает **одну команду за запуск**. Команда — это JSON-объект, у которого
ровно один ключ верхнего уровня: **имя операции**. Всё остальное — её параметры.

## Запуск

```
gate.atol.piot.exe --send <файл.json> [--no-dry-run] [--allow-fiscal]
```

| Ключ | Смысл |
|---|---|
| `--send <файл>` | выполнить команду из файла |
| `--dry-run` | **по умолчанию**: ничего не отправлять в кассу, только собрать XML и записать в журнал |
| `--no-dry-run` | отправлять команды в кассу |
| `--allow-fiscal` | разрешить фискальные операции (чеки, закрытие смены) |

Перед запуском должен быть поднят хост компоненты:

```
gate.1c.addin.proxy.exe --http-port 8082 --http-bind 127.0.0.1 --dll fptr10_1c_win32_10_10_8_21.dll
```

## Общий вид команды

```json
{ "ИмяОперации": { ...параметры... } }
```

## Виды операций

| Файл | Операция | Метод компоненты |
|---|---|---|
| `01_Продажа.json` | `НапечататьЧек`, `ТипЧека: "Продажа"` | `СформироватьЧек` |
| `02_Возврат.json` | `НапечататьЧек`, `ТипЧека: "Возврат"` | `СформироватьЧек` |
| `03_Продажа_маркированного_товара.json` | `НапечататьЧек` с кодом маркировки | `СформироватьЧек` |
| `04_СнятьОтчетБезГашения.json` | `СнятьОтчетБезГашения` | `НапечататьОтчетБезГашения` |
| `05_СнятьОтчетСГашением.json` | `СнятьОтчетСГашением` | `ЗакрытьСмену` (Z-отчёт) |
| `06_ОткрытьЯщик.json` | `ОткрытьЯщик` | `ОткрытьДенежныйЯщик` |
| `07_ОтменитьЧек.json` | `ОтменитьЧек` | `ЗакрытьСессиюРегистрацииКМ` |

## Как читать описания

В каждом файле:

* `запрос` — готовый JSON, который кладётся в файл и передаётся ключу `--send`;
* `описаниеПолей` — что означает каждое поле и обязательно ли оно;
* `ответ` — что шлюз печатает в консоль (и пишет в журнал `logs\`);
* `примечания` — особенности, проверенные на живой кассе.

## Что смотреть в журнале

Шлюз пишет `logs\gate.atol.piot_ГГГГ-ММ-ДД.log`. Там видно:

* `[НапечататьЧек] XML, который будет передан:` — собранный `CheckPackage`;
* `---> Метод: {...}` и `<--- Метод: {...}` — полный обмен с компонентой в JSON-RPC;
* `РЕЗУЛЬТАТ: {...}` — итоговый ответ шлюза.
